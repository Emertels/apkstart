Instalar Android no Disco Virtual

A janela da máquina virtual está aberta. Siga estes 6 passos uma única vez; depois o ApkStart iniciará direto do disco.

  1. Menu de Boot: Use a tecla ↓ para selecionar Installation - Install Android-x86 to harddisk e pressione Enter
  2. Partição: Selecione Create/Modify partitions; na pergunta sobre GPT, escolha No
  3. cfdisk: New → Primary → Enter no tamanho → Bootable → Write → digite yes → Quit
  4. Formatação: Selecione vda1 → formato ext4 → Yes
  5. Bootloader e Sistema: Install GRUB escolha Yes; Install /system as read-write escolha Yes
  6. Conclusão: Quando chegar a 100%, clique no botão "Concluí a instalação" abaixo (o ApkStart reiniciará automaticamente)

Se informar que o ADB não conectou: na janela da VM pressione Ctrl+Alt+F1, execute setprop service.adb.tcp.port 5555, stop adbd, start adbd, e pressione Ctrl+Alt+F7 para voltar à tela gráfica.
